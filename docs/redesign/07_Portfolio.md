## 4. รายละเอียด

### 4.1 สีหมวดหมู่ชุดใหม่

แก้ `PortfolioCategory.color` ใน `Core/Models/PortfolioItem.swift`

| หมวด | เดิม | ใหม่ |
|---|---|---|
| เกียรติบัตร | `warning` | `Theme.Colors.primary` — `C96F4A` |
| กิจกรรม | `primary` | `subjectPalette[1]` — `7D8F69` เขียวมะกอก |
| จิตอาสา | `pink` | `subjectPalette[4]` — `8E6B9E` ม่วงหม่น |
| การแข่งขัน | `danger` | `subjectPalette[3]` — `6B7FA3` น้ำเงินหม่น |
| โปรเจกต์ | `indigo` | `subjectPalette[5]` — `B08D57` ทอง |

⚠️ **นี่คือการแก้ไฟล์ `Core/Models/` ซึ่งปกติห้ามแตะ — อนุญาตเฉพาะครั้งนี้เพราะ:**
`color` เป็น **computed property** ไม่ใช่ stored property → **ไม่กระทบ SwiftData schema ไม่มีทาง crash**
**ห้ามแตะ `categoryRaw` · `startDate` · `endDate` · `images` หรือ `init` ใดๆ ในไฟล์นั้นเด็ดขาด**

ป้ายหมวดใช้ `color.opacity(0.15)` เป็นพื้น + `color` เป็นตัวอักษรเหมือนเดิม (สีใหม่ทั้ง 5 ตัวเข้มพอให้อ่านออกบนพื้นจางของตัวเอง)

### 4.2 การ์ดสรุปด้านบน

```
┌──────────────────────────────────────────────┐
│ ทั้งหมด 12 ชิ้น                 ล่าสุด 12 ส.ค. │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓    │
│ ● เกียรติบัตร 5  ● กิจกรรม 3  ● จิตอาสา 2      │
│ ● แข่งขัน 1  ● โปรเจกต์ 1                      │
└──────────────────────────────────────────────┘
```

- แถบเดียวแบ่งสัดส่วนตามจำนวนของแต่ละหมวด สูง 7pt มุมมน
- หมวดที่มี 0 ชิ้น **ไม่ต้องแสดงทั้งในแถบและในรายการจุด**
- `"ล่าสุด <วัน>"` มาจาก `items.first?.startDate` (query เรียง `.reverse` อยู่แล้ว)
- **การ์ดนี้ไม่แสดงเมื่อกรองหมวดอยู่** — ตอนกรองแล้วสัดส่วนไม่มีความหมาย
- ซ่อนทั้งใบเมื่อ `items.isEmpty`

### 4.3 toolbar · ค้นหา · เรียงลำดับ

```
ผลงาน                          🔍   [ + ผลงาน ]
```

- ปุ่ม `+ ผลงาน` มีพื้น `primary` แบบเดียวกับ `06_TCAS.md` — สองหน้านี้เข้าจากเมนูหลักเหมือนกัน ต้องพูดภาษาเดียวกัน
- `.searchable(text:)` ค้นจาก `title` และ `detail` (case-insensitive) — ทำงานทับกับ chip กรองหมวด (AND กัน)
- **เรียงลำดับอยู่ใน `Menu` ท้ายแถว chip** ไม่ใช่ toolbar (toolbar เต็มแล้ว):

| ตัวเลือก | เรียงตาม |
|---|---|
| ล่าสุดก่อน (default) | `startDate` มาก → น้อย |
| เก่าสุดก่อน | `startDate` น้อย → มาก |
| ชื่อ ก–ฮ | `title` ด้วย `localizedStandardCompare` |
| ตามหมวดหมู่ | `PortfolioCategory.allCases` order แล้วตามด้วย `startDate` |

⚠️ `@Query(sort:)` ปัจจุบัน hard-code `.reverse` ไว้ → **เปลี่ยนเป็น `@Query` ธรรมดาแล้วเรียงใน computed property แทน** ไม่ต้องไปยุ่งกับ `@Query` dynamic sort ซึ่งซับซ้อนกว่าที่จำเป็น

เก็บสถานะการเรียงใน `@State` ธรรมดา ไม่ต้องจำข้ามการเปิดหน้า

### 4.4 กดค้างที่การ์ด → context menu

```swift
.contextMenu {
    Button("ดูรายละเอียด", systemImage: "eye") { … }
    Divider()
    Button("ลบผลงาน", systemImage: "trash", role: .destructive) { pendingDelete = item }
}
```

- "ลบ" **ต้องเด้ง alert ยืนยันเหมือนในหน้ารายละเอียด** ข้อความเดียวกัน (`"การลบจะลบรูปภาพที่แนบไว้ทั้งหมดด้วย และไม่สามารถย้อนกลับได้"`)
- ⚠️ **จุดที่พังง่ายที่สุดของสเปคนี้:** ตอนนี้ `deleteItem()` เป็น `private func` อยู่ใน `PortfolioDetailView` และข้างในมี
  ```swift
  for image in item.images { PortfolioImageStore.delete(image.filename) }
  ```
  ถ้าเขียนโค้ดลบในกริดขึ้นมาใหม่แล้ว **ลืมบรรทัดลบไฟล์รูป → ไฟล์รูปค้างในเครื่องถาวร ลบไม่ได้อีกเลย** (แถวหายจากฐานข้อมูลแล้ว ไม่มีใครรู้ชื่อไฟล์อีก)
  → **บังคับ: ย้าย `deleteItem` ออกมาเป็นไฟล์ใหม่ `PortfolioItemActions.swift`**
  ```swift
  enum PortfolioItemActions {
      static func delete(_ item: PortfolioItem, in context: ModelContext)
  }
  ```
  แล้วให้ **ทั้ง** `PortfolioDetailView` และ context menu เรียกตัวเดียวกัน **ห้ามเขียนโค้ดลบซ้ำสองที่**

### 4.5 การ์ดในกริด

```
┌──────────────────┐
│   [รูปปก 4:3]  3 │
├──────────────────┤
│ [เกียรติบัตร]     │  ← ป้ายหมวดขึ้นมาอยู่บนชื่อ
│ เกียรติบัตรแข่งขัน │
│ คณิตศาสตร์        │
│ ได้รางวัลรองชนะ… │  ← detail จาง 2 บรรทัด (ใหม่)
│ 12 ส.ค. 2568     │
└──────────────────┘
```

- **ป้ายหมวดย้ายขึ้นมาก่อนชื่อ** — เดิมอยู่ล่างสุดใต้วันที่ ทำให้ตาต้องกวาดลงไปหา
- เพิ่ม `detail` แบบ `.lineLimit(2)` สี `textSecondary` — ซ่อนทั้งบรรทัดถ้า `detail.isEmpty`
- การ์ดเพิ่ม `cardStroke` 1pt (ตอนนี้มีแต่เงา) เพื่อให้เห็นขอบในโหมดมืด
- radius `Theme.Radius.card` (18)

### 4.6 หน้ารายละเอียด

- ใส่หัวข้อ `"รายละเอียด"` เหนือ `item.detail` (ตอนนี้เป็น `Text` ลอยๆ)
- ป้ายหมวด + ช่วงวันคงเดิม
- **ปุ่มลบคงตำแหน่งเดิม** — Few เลือกไว้
- แกลเลอรี: เพิ่มตัวนับ `"2 / 5"` มุมขวาล่างของรูป (`TabView(.page)` มีจุดอยู่แล้ว แต่เกิน 5 รูปจุดจะเล็กจนนับไม่ได้)

### 4.7 empty state

```
ยังไม่มีผลงาน
เก็บเกียรติบัตร กิจกรรม จิตอาสา และโปรเจกต์ไว้ที่นี่
พอถึงเวลายื่นพอร์ตรอบ 1 จะได้ไม่ต้องรื้อหาทีหลัง
                [ เพิ่มผลงานชิ้นแรก ]
```

## 8. เกณฑ์เสร็จ

1. หัวข้อหน้าเป็น **"ผลงาน"** ภาษาไทย และเมนูใน Dashboard เขียนตรงกัน
2. **ป้าย "การแข่งขัน" ไม่ใช่สีแดงแล้ว** · "เกียรติบัตร" ไม่ใช่สีเหลืองเตือนแล้ว
3. เห็นการ์ดสรุปบนสุด บอกจำนวนรวมและแยกตามหมวด · กดกรองหมวดแล้วการ์ดสรุปหายไป
4. chip ทุกอันมีตัวเลข
5. ค้นหาคำที่อยู่ใน `detail` (ไม่ใช่ชื่อ) แล้วเจอ
6. เปลี่ยนการเรียงเป็น "ชื่อ ก–ฮ" แล้วลำดับเปลี่ยนจริง
7. **กดค้างที่การ์ดในกริด → เมนู "ดูรายละเอียด / ลบผลงาน" · กดลบ → alert ถามก่อน**
8. ลบจากกริดแล้ว **ไฟล์รูปหายจากเครื่องด้วย** (ตรวจโดยลบแล้วเพิ่มใหม่ ดูว่าพื้นที่ไม่บวมขึ้นเรื่อยๆ)
9. การ์ดที่มี `detail` แสดง 2 บรรทัดจาง · ที่ไม่มีไม่เหลือช่องว่าง
10. ยังไม่มีผลงาน → empty state อธิบายว่าเก็บไปทำไม พร้อมปุ่มเพิ่มชิ้นแรก
11. แกลเลอรีในหน้ารายละเอียดมีตัวนับ "2 / 5"
12. สลับ dark mode → ขอบการ์ดในกริดยังเห็น
