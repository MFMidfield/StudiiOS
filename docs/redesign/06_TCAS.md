## 3. ตัด / เก็บ / ย้าย

### ✂️ ตัดทิ้ง

| ตัด | เหตุผล |
|---|---|
| `Toggle("สอบไปแล้ว")` ใน `MyScoresView` | กรอกคะแนน = สอบแล้วโดยอัตโนมัติ (§4.4) |
| แถวปุ่ม "เพิ่มคณะเป้าหมาย" ท้าย Section | ย้ายขึ้น toolbar |
| เลข leverage ทศนิยม 3 ตำแหน่ง | เปลี่ยนเป็นความยาวแถบ (§4.3) |
| Section "คะแนนเป้าหมาย" ใน `TCASEntryDetailView` | ย้ายขึ้นการ์ดคะแนน (§4.2) |
| เชิงอรรถ `"ดันได้อีก" = คะแนนรวมที่จะเพิ่ม…` | กลายเป็นคำอธิบายใต้หัวข้อการ์ดแทน |

### ✅ เก็บไว้

- **`TCASScoreEngine` ทั้งหมด** — `currentScore` · `ceilingScore` · `gap` · `leverage` · `requiredAverage` · `totalPercent`
- **ข้อความในโหมดล็อกทั้ง 5 บรรทัด** — เป็นข้อความที่แผนเดิม §4.3 กำหนดไว้เป๊ะ **ห้ามเขียนใหม่** แค่จัดหน้าใหม่
- **ข้อความตอน `requiredAveragePercent > 100`** — `"ถึงได้เต็มทุกวิชาก็ยังไม่ถึงเป้าที่ตั้งไว้ ลองปรับเป้าหมาย หรือดูคณะอันดับรองที่บันทึกไว้"` ใช้ `warning` **ห้ามใช้สีแดง** (กฎ §4.3)
- **คำเตือนน้ำหนักไม่ครบ 100%** และข้อความ `"ไม่ครบ 100% ก็บันทึกได้ — บางคณะมีสัมภาษณ์/แฟ้มสะสมงานถ่วงน้ำหนักด้วย"`
- ปุ่ม "เปิดดูเกณฑ์ใน mytcas" + ช่องวางลิงก์ระเบียบการ (กฎเหล็ก §0.3)
- `TCASWeightSetupView` โหมดรายวิชา/กลุ่ม — **ทาสีอย่างเดียว**
- `SOPEditorView` · `SOPGuideSheet` — **ทาสีอย่างเดียว**

### ➡️ ย้ายที่

| ของ | จาก | ไป |
|---|---|---|
| ปุ่มเพิ่มคณะ | ท้าย Section | **toolbar ขวาบน ปุ่มมีพื้น `"+ คณะ"`** |
| คะแนนเป้าหมาย | Section แยกในหน้า detail | มุมขวาบนของการ์ดคะแนน + ปุ่มดินสอ → `TCASTargetSheet` |

## 4. หน้าตาใหม่

### 4.1 `TCASPlannerView` — ลิสต์กลายเป็นการ์ดเทียบคะแนน

```
วางแผน TCAS                        [ + คณะ ]   ← ปุ่มมีพื้น primary
──────────────────────────────────────────────
┌ 📊 คะแนนสอบของฉัน                        › ┐
│    กรอกแล้ว 4 จาก 9 วิชา                    │
└──────────────────────────────────────────────┘

คณะเป้าหมาย 3 คณะ

┌──────────────────────────────────────────────┐
│ วิศวกรรมศาสตร์                        42.3   │
│ จุฬาฯ · รอบ 3                    เพดาน 78.9  │
│ ▓▓▓▓▓▓░░░░░░│░░░                             │
│ เป้า 70 · อีก 27.7          [น้ำหนัก 85%]    │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ วิทยาศาสตร์                           61.8   │
│ มหิดล · รอบ 2                    เพดาน 84.2  │
│ ▓▓▓▓▓▓▓▓▓│▓░░░░                              │
│ เป้า 58 · ถึงเป้าแล้ว                        │
└──────────────────────────────────────────────┘
┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
│ อักษรศาสตร์             [ยังไม่ตั้งน้ำหนัก]  │  ← เส้นประ
│ ธรรมศาสตร์ · รอบ 1                          │
└ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
```

**แถบคะแนน 3 ชั้นในแท่งเดียว:**
- ช่วงเข้ม `primary` = `currentScore` (คะแนนที่ล็อกแล้ว)
- ช่วงอ่อน `primarySoft` = ส่วนที่ยังไม่สอบ (จาก `current` ถึง `ceiling`)
- ขีดดำแนวตั้ง = `targetScore` (ไม่แสดงถ้า `targetScore == 0`)
- ทั้งแท่งสเกล 0–100

**สีแถบตามสถานะ:** ถึงเป้าแล้ว → `success` family · ยังไม่ถึง → `primary` family
**ห้ามใช้สีแดงกับคณะที่คะแนนยังน้อย** — ยังไม่สอบไม่ใช่ความล้มเหลว

**ป้ายมุมขวาล่าง** แสดงเฉพาะเมื่อ `abs(totalPercent - 100) > 0.01` → `"น้ำหนัก 85%"` สี `warning`

**การ์ดคณะที่ `entry.weights.isEmpty`:** ขอบเส้นประ · ไม่มีแถบ · ป้าย `"ยังไม่ตั้งน้ำหนัก"` · แตะแล้วไปหน้า detail ตามเดิม

**แถว "คะแนนสอบของฉัน"** เพิ่มบรรทัดรอง `"กรอกแล้ว N จาก M วิชา"` — นับจาก `records.filter { $0.hasTaken }.count` เทียบ `TCASExamCatalog.all.count`

**ปัดซ้ายลบคณะ** — เก็บไว้ แต่ **เพิ่ม alert ยืนยัน** พร้อมบอกว่าจะลบน้ำหนักกับ SOP ของคณะนั้นด้วย (ตอนนี้ลบทันทีไม่ถาม)

**empty state** เมื่อยังไม่มีคณะเลย:
> "ยังไม่มีคณะเป้าหมาย
> เพิ่มคณะที่อยากเข้า แล้วกรอกน้ำหนัก % ของแต่ละวิชา แอปจะคำนวณให้ว่าต้องได้อีกเท่าไรถึงจะถึงเป้า"
> พร้อมปุ่ม "เพิ่มคณะแรก"

### 4.2 การ์ดคะแนน — แยกเป็น 2 ใบ

**ใบที่ 1 — คะแนนรวม**

```
คะแนนรวมตอนนี้                    เป้า
42.3  เต็มที่ได้ถึง 78.9          70 ✏️
▓▓▓▓▓▓░░░░░░│░░░
แถบเข้ม = ที่ได้แล้ว · แถบอ่อน = ที่ยังไม่สอบ · ขีดดำ = เป้า

[⚠ น้ำหนักรวม 85.0% ยังไม่ครบ 100%]     ← เฉพาะเมื่อไม่ครบ

┌────────────────────────────────────────┐
│ ต้องได้เฉลี่ย 75.6% ในวิชาที่เหลือ      │  ← พื้น primarySoft
│ ล็อกแล้ว 28.40 · เหลือน้ำหนัก 55%      │
└────────────────────────────────────────┘
```

- เลข `42.3` ใช้ `textPrimary` **ไม่ใช่ `primaryDeep`** (สีส้มสงวนให้ของที่กดได้)
- เป้ามุมขวาบน + ไอคอนดินสอ → `TCASTargetSheet` — **ถ้า `targetScore == 0` แสดงคำว่า `"ตั้งเป้า"` แทนเลข**
- กล่องสรุปโหมดล็อกแสดงเฉพาะเมื่อ `hasAnyLocked == true`
  - บรรทัดบน = ข้อสรุปจาก `lockConclusion` เดิม
  - บรรทัดล่าง = ย่อ 4 บรรทัดของ `lockSection` เดิมเหลือ `"ล็อกแล้ว X · เหลือน้ำหนัก Y%"`
  - **แตะกล่องแล้วขยายดูครบทั้ง 4 บรรทัด** (`DisclosureGroup`) — ข้อมูลไม่หาย แค่ไม่ยัดมาตั้งแต่แรก ตรงตามเจตนา §4.3 ที่ว่า "ต้องแสดงที่มาของตัวเลขครบ"
- `gap` ("ห่างจากเป้า / อีก X") **ย้ายไปอยู่ในลิสต์คณะแทน** ไม่ต้องซ้ำในหน้า detail

**ใบที่ 2 — ดันวิชาไหนคุ้มสุด**

```
ดันวิชาไหนคุ้มสุด
ถ้าได้เต็มในวิชานั้น คะแนนรวมจะเพิ่มเท่าไร

A-Level คณิต 1   ▓▓▓▓▓▓▓▓▓▓   +18.8
TGAT2            ▓▓▓▓▓▓▓▓░░   +15.0
A-Level ฟิสิกส์   ░░░░░░░░░░   สอบแล้ว     ← จาง
```

- **ความยาวแถบ = `leverage`** เทียบกับตัวที่สูงสุด (normalize 0–1) → ยังโชว์ "ความคุ้ม" ครบตามกฎ §4.2 แค่ไม่ใช่ตัวเลขดิบ
- **ตัวเลขขวา = `headroom`** (ดันได้อีกกี่คะแนนรวม)
- วิชาที่ `hasTaken == true` → แถบว่าง · `.opacity(0.5)` · ขวาเขียนว่า `"สอบแล้ว"`
- แสดง 3 อันดับแรกเหมือนเดิม
- ⚠️ **ห้ามแสดงแถบโดยไม่มีตัวเลข headroom** และ **ห้ามแสดง headroom โดยไม่มีแถบ** — กฎ §4.2 คือต้องเห็นทั้ง "คุ้ม" และ "ดันได้อีก" พร้อมกัน ไม่งั้นผู้ใช้จะไปดันวิชาที่คุ้มแต่เต็มแล้ว

### 4.3 `TCASTargetSheet` — ไฟล์ใหม่

- `.presentationDetents([.height(260)])`
- ช่องกรอกคะแนนเป้า 0–100 + ปุ่มลัด (50 · 60 · 70 · 80)
- ปุ่ม **"ไม่ระบุเป้า"** เขียน `entry.targetScore = 0` — **นี่คือทางที่ทำให้ `0 = ไม่ระบุ` ชัดเจน** แทนที่จะให้พิมพ์ 0 เอง
- แสดงข้อความเตือนถ้าเป้ามากกว่า `ceilingScore` ปัจจุบัน: `"เป้านี้สูงกว่าคะแนนสูงสุดที่เป็นไปได้ (78.9) — ต้องเพิ่มน้ำหนักวิชาหรือปรับเป้า"`

### 4.4 `MyScoresView` — ตัด Toggle

**พฤติกรรมใหม่:**

| ผู้ใช้ทำ | ผล |
|---|---|
| ช่องว่าง (ยังไม่เคยกรอก) | **ไม่มี `TCASScoreRecord` แถวนั้นเลย** · ช่องแสดง placeholder `"—"` |
| พิมพ์ตัวเลข (รวมถึง `0`) | สร้าง/อัปเดต record · `hasTaken = true` · `score = ค่าที่พิมพ์` |
| ลบจนว่าง | **`context.delete(record)`** — ลบแถวทิ้ง ไม่ใช่ตั้ง `score = 0` |

- **binding ต้องเป็น `Double?` ไม่ใช่ `Double`** — `nil` คือ "ยังไม่กรอก" ซึ่งต่างจาก "กรอกว่า 0"

> 🔴 **ตรวจโค้ดจริงแล้วพบว่าจุดนี้พลาดไม่ได้** — `TCASScoreEngine.breakdown()` เขียนว่า
> ```swift
> rawScore: matched?.score   // matched = scores.first { $0.examCode == weight.examCode }
> ```
> `rawScore` เป็น `nil` **ก็ต่อเมื่อไม่มี record แถวนั้นเลย** ไม่ใช่ตอน `hasTaken == false`
> ถ้าลบจนว่างแล้วยังทิ้ง record ที่ `score = 0` ไว้ → `rawScore = 0` → `currentContribution = 0`
> → **คะแนนรวมจะนับวิชานั้นเป็น 0 แทนที่จะเป็น "ยังไม่ระบุ"** ซึ่งผิดกฎ §4.4 ของแผนเดิมที่เขียนคอมเมนต์ไว้ในโค้ดเองว่า
> `// nil = ยังไม่ระบุ (ห้ามนับเป็น 0 — §4.4)`
>
> ⚠️ **นี่เป็นบั๊กที่มีอยู่แล้วในโค้ดปัจจุบันด้วย** — `MyScoresView.update()` สร้าง record ทันทีที่ binding ถูกแตะ
> แม้ผู้ใช้จะยังไม่กรอกอะไร ทำให้คะแนนถูกนับเป็น 0 โดยไม่ตั้งใจ **สเปคนี้แก้บั๊กนั้นไปในตัว**
- ⚠️ **ห้ามแก้ `TCASScoreRecord` model** — `hasTaken` ยังอยู่เหมือนเดิม แค่ UI เป็นคนกำหนดค่าให้ ไม่ใช่ผู้ใช้กดเอง
  เหตุผล: `TCASScoreEngine.requiredAverage` ใช้ `hasTaken` แยกวิชาที่ล็อกแล้วออกจากที่ยังไม่สอบ ถ้าความหมายเพี้ยนตัวเลขทั้งโมดูลเพี้ยนตาม
- แต่ละแถวเหลือ **บรรทัดเดียว**: ชื่อวิชา · ช่องกรอก · `/ 100`
- วิชาที่กรอกแล้วให้ตัวเลขเป็น `textPrimary` ตัวหนา · ที่ยังไม่กรอกเป็น `textSecondary`
- หัว Section แต่ละกลุ่มเพิ่มตัวนับ `"TGAT · กรอกแล้ว 2/3"`

### 4.5 กรอกคะแนนแล้วเห็นผลกระทบ (ปัญหา 7)

ท้าย `MyScoresView` เพิ่ม section:

```
มีผลกับคณะเป้าหมาย
วิศวกรรมศาสตร์ จุฬาฯ      42.3 → 51.7  ↑
วิทยาศาสตร์ มหิดล         61.8 → 61.8
```

- คำนวณจาก `TCASScoreEngine.currentScore` ของแต่ละ entry ด้วยคะแนนล่าสุด — **อ่านอย่างเดียว ไม่เขียนอะไร**
- ถ้ายังไม่มีคณะเป้าหมาย → ซ่อน section นี้ทั้งอัน
- ⚠️ ไม่ต้องเก็บค่า "ก่อนหน้า" ในฐานข้อมูล — แสดงแค่คะแนนปัจจุบันของแต่ละคณะก็พอ **ลูกศร `↑` แสดงเฉพาะเมื่อคะแนนเปลี่ยนภายใน session นี้** (เก็บ snapshot ตอนเปิดหน้าใน `@State`)

## 7. เกณฑ์เสร็จ

1. เปิดหน้า TCAS → **เห็นคะแนนของทุกคณะในจอเดียว** ไม่ต้องกดเข้าไปทีละคณะ
2. คณะที่ยังไม่ตั้งน้ำหนักเป็นการ์ดเส้นประพร้อมป้ายบอก
3. ปุ่ม `+ คณะ` อยู่มุมขวาบน มีพื้นสีส้ม
4. ยังไม่มีคณะเลย → เห็น empty state ที่อธิบายว่าโมดูลนี้ทำอะไร พร้อมปุ่มเพิ่มคณะแรก
5. ปัดซ้ายลบคณะ → **มี alert ถามก่อน** บอกว่าน้ำหนักกับ SOP จะหายด้วย
6. ในหน้าคณะ: เป้าอยู่มุมขวาบนการ์ด กดดินสอ → sheet เปิด → กด "ไม่ระบุเป้า" ได้ → ขีดเป้าบนแถบหายไป
7. การ์ด "ดันวิชาไหนคุ้มสุด" แยกใบ · **ไม่มีเลขทศนิยม 3 ตำแหน่งในจอแล้ว** · วิชาที่สอบแล้วจางและเขียนว่า "สอบแล้ว"
8. กล่องโหมดล็อกแตะแล้วขยายเห็นครบ 4 บรรทัดเดิม
9. หน้าคะแนนสอบ: **ไม่มี Toggle แล้ว** · แต่ละวิชาบรรทัดเดียว · พิมพ์คะแนนแล้วตัวเลขเข้ม · ลบจนว่างแล้วกลับเป็นจาง
10. **กรอก 0 ในวิชาหนึ่ง → วิชานั้นต้องถูกนับว่า "สอบแล้ว"** (ดูได้จากการ์ด leverage ที่ต้องขึ้นว่าสอบแล้ว)
11. ท้ายหน้าคะแนนเห็น section "มีผลกับคณะเป้าหมาย" อัปเดตตามที่กรอก
12. สลับ dark mode แล้วแถบคะแนนทั้งสองชั้นยังแยกออกจากกันได้
