# 04 · GradeCenter — หน้าเกรดและ GPAX

> โมดูล `StudiiOS/Features/GradeCenter/` (6 ไฟล์ · 924 บรรทัด)
> ⚠️ **`GPAXCalculator` เป็น logic ล้วน ห้ามแตะแม้แต่บรรทัดเดียว** — ทุกตัวเลขในหน้านี้มาจากมัน โมดูลนี้มีหน้าที่จัดรูปแบบอย่างเดียว

---

## 1. สภาพปัจจุบัน

```
GradeCenterView
├── GPAXSummaryCard      เลข GPAX + range bar + ข้อความสถานะ + TargetQuickSetter (ฝังอยู่)
└── TermGradeListSection 6 แถวคงที่ ม.4/1 – ม.6/2
      แถวที่จบแล้ว  → NavigationLink → TermGradeEditView
      แถวปัจจุบัน   → กดไม่ได้ ขึ้น "กำลังเรียน" สีส้ม
      แถวอนาคต     → กดไม่ได้ ขึ้น "ต้องได้ 3.72"
```

## 2. ปัญหา UX

| # | ปัญหา | ระดับ |
|---|---|---|
| 1 | **"พื้น / เพดาน" เป็นศัพท์ที่นักเรียนไม่รู้จัก** — แปลตรงจาก floor/ceiling ทั้งที่เป็นข้อมูลมีประโยชน์ที่สุดในการ์ด | สูง |

| 8 | ยังไม่ตั้งระดับชั้น = จอเต็มด้วยแถวว่าง 6 แถวที่เขียน "ยังไม่มีข้อมูล" เหมือนกันหมด | กลาง |
| 9 | ลิสต์ 6 แถวหน้าตาเป็นสเปรดชีต ครึ่งหนึ่งเป็นแถวว่าง ไม่สื่อว่านี่คือ "เส้นทาง 3 ปี" | กลาง |

## 3. ตัด / เก็บ / ย้าย

### ✂️ ตัดทิ้ง

| ตัด | เหตุผล |
|---|---|
| `TargetQuickSetter` (private struct ใน `GPAXSummaryCard.swift`) | แทนด้วยปุ่มดินสอที่ใช้ได้ตลอดเวลา (§4.2) |
| section ตั้งเป้า GPAX ใน `SettingsView` | เหลือที่ตั้งเป้าที่เดียว → **งานของ `05_Settings.md`** |
| ข้อความ `"พื้น X · เพดาน Y · เป้า Z"` | แทนด้วยป้ายที่ปลาย bar + ประโยคภาษาคน (§4.2) |

### ✅ เก็บไว้

- `GPAXCalculator` ทั้งหมด — **ห้ามแตะ**
- `@AppStorage` "ping" 7 ตัวใน `GradeCenterView` — **ห้ามลบแม้จะดูเหมือนไม่ได้ใช้** มันคือกลไกที่ทำให้ SwiftUI รู้ว่า UserDefaults เปลี่ยน (มีคอมเมนต์อธิบายอยู่ในไฟล์แล้ว)
- กฎ "แก้ได้เฉพาะเทอมที่จบแล้ว" — **เป็นกฎที่ถูกต้อง** เพราะเกรดเทอมปัจจุบันจะถูก `GPAXCalculator` เมินทั้งหมด ไม่ใช่บั๊ก แค่ต้องอธิบายให้ผู้ใช้เข้าใจ
- `TermGradeEditView` ทั้งหมด รวมโหมด "กรอกละเอียด" ที่ seed วิชาจากตารางสอน
- `GradeLevelSheet` · `CumulativeGPAXSheet`
- แถวเทอมอนาคตยังแสดง `"ต้องได้ 3.72"` — Few เลือกคงไว้ทุกแถว

### ➡️ ย้ายที่

| ของ | จาก | ไป |
|---|---|---|
| ตั้งเป้า GPAX | `TargetQuickSetter` + Settings | ปุ่มดินสอมุมขวาบนการ์ด → `GPAXTargetSheet` (ไฟล์ใหม่) |
| "ต้องได้ 3.72" ของเทอมอนาคต | ข้อความอย่างเดียว | ความสูงของแท่งจางในกราฟ **และ** ข้อความในแถว (ทั้งสองอย่าง) |

## 4. หน้าตาใหม่

### 4.1 หัวข้อหน้า

```swift
// เดิม: activeTerm (เทอมที่เปิดดูตารางสอน) — ผิด
// ใหม่: GPAXSettings.currentSortKey (เทอมจริงของนักเรียน) — ตรงกับตัวเลขทั้งหน้า
"เกรดและ GPAX · ม.5 เทอม 1"
```
ถ้า `GPAXSettings.currentSortKey == nil` → `"เกรดและ GPAX"` เฉยๆ
**ห้ามใช้ `activeTermID` ในไฟล์นี้อีกเลย** — ลบ `@AppStorage(TermStore.activeTermKey)` และ `@Query terms` ที่ใช้หา `activeTerm` ออก (แต่ `@Query terms` ยังต้องอยู่เพราะ `gpaxTermInputs` ใช้)

### 4.2 `GPAXSummaryCard` — โครงใหม่

```
┌──────────────────────────────────────────────┐
│ GPAX สะสม · จาก 4 เทอม          เป้า        │
│ 3.29                            3.50 ✏️      │
│                                              │
│ ▓▓▓▓▓▓▓▓░░░░│░░░░░░░░                        │
│ 3.15                              3.61       │
│ ถ้าเลิกตั้งใจเลยจะจบที่ 3.15                  │
│ ถ้าได้ 4.00 ทุกเทอมที่เหลือจะจบที่ 3.61       │
│                                              │
│ ┌────────────────────────────────────────┐   │
│ │ ต้องได้เทอมละ 3.72 ขึ้นไป              │   │
│ │ เหลืออีก 3 เทอม                        │   │
│ └────────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

- **เลข GPAX ใช้ `textPrimary` ไม่ใช่ `primaryDeep`** — เลขนี้เป็นข้อเท็จจริง ไม่ใช่ปุ่ม สีส้มควรสงวนไว้ให้ของที่กดได้
- **เป้ามุมขวาบน** — เลข + ไอคอนดินสอ กดได้ตลอดเวลา แม้ยังไม่เคยตั้ง (ตอนยังไม่ตั้งขึ้นว่า `"ตั้งเป้า"`)
- **ป้ายเลขที่ปลาย bar ทั้งสองข้าง** (`floor` ซ้าย · `ceiling` ขวา) ขีดเป้าเป็นแท่งสูงกว่า bar เล็กน้อยให้เห็นชัด
- **แทน "พื้น/เพดาน" ด้วยประโยคภาษาคน 2 บรรทัด:**
  - `"ถ้าเลิกตั้งใจเลยจะจบที่ <floor>"`
  - `"ถ้าได้ 4.00 ทุกเทอมที่เหลือจะจบที่ <ceiling>"`
- **ข้อความสถานะย้ายลงกล่องพื้น `primarySoft`** + บรรทัดรอง `"เหลืออีก N เทอม"`
  ข้อความสถานะทุกแบบ (`achieved` / `onTrack` / `tight` / `outOfReach` / `finished`) **ใช้ข้อความเดิมจาก `copy(for:gpax:)` ทั้งหมด ห้ามเขียนใหม่** — มันถูกกำหนดไว้ในแผน GPAX เดิมแล้ว
  สีกล่อง: `outOfReach` → พื้น `danger.opacity(0.12)` · `achieved`/`finished` → `success.opacity(0.12)` · ที่เหลือ → `primarySoft`

### 4.3 empty state — ซ่อนลิสต์

เมื่อ `gpaxResult == nil` หรือ `result.gpax == nil`:
- แสดง**การ์ดเดียว** พร้อมปุ่ม `"ตั้งระดับชั้นปัจจุบัน"` (ถ้า `currentSortKey == nil`) หรือ `"เพิ่มผลการเรียนเทอมแรก"`
- **ไม่แสดง `TermGradeListSection` เลย** — ไม่ต้องโชว์ 6 แถวว่าง
- ปุ่ม "เพิ่มผลการเรียนเทอมแรก" push ไป `TermGradeEditView` ของเทอมที่จบล่าสุด (`currentSortKey` ตัวก่อนหน้าใน `upperBandSortKeys`)

### 4.4 `TermGradeListSection` — กราฟแท่ง + ลิสต์

**ส่วนบน: `TermGradeChart` (ไฟล์ใหม่)**

แท่ง 6 อัน เรียงตาม `GPAXCalculator.upperBandSortKeys`

| ประเภทแท่ง | ความสูง | หน้าตา | กดได้ |
|---|---|---|---|
| เทอมที่กรอกแล้ว | `gpa / 4.0` | ทึบ `primary` · เลข GPA อยู่บนหัวแท่ง | ✅ push `TermGradeEditView` |
| เทอมปัจจุบัน | `requiredAverage / 4.0` | ลายทแยง + ขอบประ `primary` · ป้าย `"กำลัง"` | ❌ |
| เทอมอนาคต | `requiredAverage / 4.0` | ทึบ `primarySoft` · เลข `requiredAverage` สีจาง | ❌ |

- **เส้นประแนวนอน = เป้า** ที่ระดับ `target / 4.0` พร้อมป้าย `"เป้า 3.50"` ชิดขวา
- ถ้า **ยังไม่ตั้งเป้า** → `requiredAverage` เป็น nil → แท่งอนาคต/ปัจจุบันสูงเท่า `gpax` ปัจจุบัน ไม่มีตัวเลข และไม่มีเส้นประ
- ถ้า state เป็น `.finished` → ไม่มีแท่งจางเลย
- แกน x ใต้กราฟ: `4/1 4/2 5/1 5/2 6/1 6/2` — เทอมปัจจุบันตัวหนาสี `primaryDeep`
- คำอธิบายใต้กราฟ 1 บรรทัด: `"แท่งทึบ = กรอกแล้ว · แท่งจาง = ระดับที่ต้องได้ · แท่งลาย = เทอมที่กำลังเรียน"`

⚠️ **ขนาดปุ่มแตะ** — การ์ดกว้าง ~340 หัก padding เหลือ ~308 หาร 6 (gap 6) ได้แท่งละ ~46pt ผ่านเกณฑ์ 44pt ของ HIG พอดี **ห้ามลด padding การ์ดหรือเพิ่ม gap** ไม่งั้นจะต่ำกว่าเกณฑ์
⚠️ แท่งต้องมี `.accessibilityLabel("ม.4 เทอม 1 เกรด 3.15")` — กราฟที่ VoiceOver อ่านไม่ได้คือกราฟที่ตกเกณฑ์

**ส่วนล่าง: ลิสต์ 6 แถว**

```
ม.4 เทอม 1   ▓▓▓▓▓▓▓░░   3.15  ›
ม.4 เทอม 2   ▓▓▓▓▓▓▓▓░   3.32  ›
ม.5 เทอม 1   ░░░░░░░░░   [เรียนอยู่]      ← พื้นแถวอ่อน
ม.5 เทอม 2   ▒▒▒▒▒▒▒▒▒   3.72
ม.6 เทอม 1   ▒▒▒▒▒▒▒▒▒   3.72
ม.6 เทอม 2   ▒▒▒▒▒▒▒▒▒   3.72
──────────────────────────────────────
กรอกได้เฉพาะเทอมที่จบแล้ว · พอขึ้นเทอมใหม่
กด "ขึ้นชั้นแล้ว" ในตั้งค่า เทอมนี้จะกรอกได้
```

- **แถบวัดในแถว** — `gpa / 4.0` สี `primary` (กรอกแล้ว) หรือ `requiredAverage / 4.0` สี `primarySoft` (อนาคต)
- **chevron เฉพาะแถวที่กดได้** — สัญญาณเดียวที่ชัดที่สุด แก้ปัญหา 2
- **แถวปัจจุบัน** — ป้ายแคปซูลสีกลาง `"เรียนอยู่"` (ไม่ใช่สีส้ม) + พื้นแถวอ่อน แก้ปัญหา 3
- แถวอนาคต `.opacity(0.55)` ทั้งแถว
- **บรรทัดอธิบายท้ายลิสต์** — บอกว่าทำไมเทอมนี้กรอกไม่ได้และต้องทำอะไร แก้ปัญหา 3

## 7. ความเสี่ยง

| เสี่ยง | กัน |
|---|---|
| ลบ `@AppStorage` ping 7 ตัวเพราะดูเหมือนไม่ได้ใช้ | มีคอมเมนต์เตือนในไฟล์แล้ว — **ห้ามลบ** ลบแล้วตัวเลขจะไม่อัปเดตตอนแก้เป้า/ขึ้นชั้น (ไม่ crash แต่ค้างเงียบๆ) |
| แท่งกราฟแคบกว่า 44pt | ห้ามลด padding การ์ด · ตรวจบนจอ 402 จริง |
| `requiredAverage` เป็น nil ตอนยังไม่ตั้งเป้า → แท่งสูง 0 | §4.4 กำหนด fallback ไว้แล้ว |
| กราฟทำให้ `TermGradeListSection` ยาวเกิน type-check | แยกเป็น `TermGradeChart.swift` ต่างหากตั้งแต่แรก |
| ลบ section เป้าใน Settings แล้วไม่มีที่ตั้งเป้าเลย | ต้องทำ `GPAXTargetSheet` ให้เสร็จก่อน แล้วค่อยให้ agent Settings ลบ |

## 8. เกณฑ์เสร็จ

เข้าหน้าเกรดจากเมนูหลัก:

1. หัวข้อขึ้น `"เกรดและ GPAX · <เทอมจริง>"` — สลับเทอมในหน้าตารางสอนแล้ว **หัวข้อนี้ไม่เปลี่ยน** (เพราะไม่ได้ผูกกับ `activeTerm` แล้ว)
2. การ์ดสรุปมีเป้าอยู่มุมขวาบน กดดินสอ → sheet ตั้งเป้าเปิด → เปลี่ยนเป็น 3.60 → ทุกตัวเลขในหน้าอัปเดตทันที
3. ปลาย bar มีเลขกำกับซ้ายขวา · ไม่มีคำว่า "พื้น" หรือ "เพดาน" ในจอแล้ว
4. เห็นกราฟแท่ง 6 เทอม — แท่งที่กรอกแล้วทึบ แท่งอนาคตจางสูงถึงระดับที่ต้องได้ มีเส้นประเป้าพาดขวาง
5. **แตะแท่ง ม.4 เทอม 1 → เปิดหน้าแก้เกรดเทอมนั้นจริง**
6. ในลิสต์ มี chevron เฉพาะแถวที่กดได้ · แถวปัจจุบันขึ้นป้าย "เรียนอยู่" สีกลาง ไม่ใช่สีส้ม
7. ท้ายลิสต์มีบรรทัดอธิบายว่าทำไมเทอมปัจจุบันกรอกไม่ได้
8. ลบข้อมูลทั้งหมดใน Settings แล้วเข้าหน้านี้ → **เห็นการ์ดเดียว ไม่มีลิสต์ 6 แถวว่าง**
9. สลับ dark mode แล้วกราฟยังอ่านออก (แท่งจางบนพื้นเข้มต้องยังเห็น)
