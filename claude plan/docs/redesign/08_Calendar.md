## 3. โครงหน้าใหม่

```
┌────────────────────────────────────────────┐
│ สิงหาคม                        [วันนี้] 🔍 │  ← หัวเดือนเปลี่ยนตามที่เลื่อน
│ 2569 ▾                                     │  ← แตะปีเพื่อเปลี่ยนปี
├────────────────────────────────────────────┤
│  อา   จ   อ   พ   พฤ   ศ   ส              │  ← ปักหมุด ไม่เลื่อนตาม
├────────────────────────────────────────────┤
│   3    4    5    6    7    8    9          │
│      ▓▓▓▓ ค่ายวิทยาศาสตร์ ▓▓▓▓             │  เลน 0 — แถบพาด 3 วัน
│      ▓สอบ▓      ▓▓ ประชุมชมรม ▓▓          │  เลน 1
│      ○ส่งชีวะ            ○ส่งคณิต          │  เลน 2 — งาน (ขอบขาว)
├────────────────────────────────────────────┤
│  10   11   12  (13)  14   15   16          │  (13) = วันนี้ วงกลมทึบ
│ ▓▓▓ สอบกลางภาค (ต่อ) ▓▓▓                   │  ท่อนต่อจากสัปดาห์ก่อน
│                ▓▓ ทัศนศึกษา ▓▓            │
│                ○ส่งชีวะ                    │
│                +2                          │  ← เกิน 4 เลน
└────────────────────────────────────────────┘
```

### 3.1 ขนาดและระยะ

| ค่า | ตัวเลข | หมายเหตุ |
|---|---|---|
| จำนวนเลนสูงสุด | **4** | เลนที่ 5 ขึ้นไปยุบเป็น `+N` |
| ความสูงแถบ | 17pt | + ระยะห่างระหว่างเลน 3pt |
| ความสูงแถวสัปดาห์ | เลขวัน 20 + (17+3)×4 + `+N` 15 + padding 12 ≈ **~127pt** | 6 แถว ≈ 760pt → **หนึ่งเดือนสูงกว่าหนึ่งจอ ต้องเลื่อน** (Few รับทราบแล้ว) |
| ความกว้างคอลัมน์บนจอ 402 | ~56pt | ชิปใส่อักษรไทยได้ ~5-6 ตัว → **ต้อง `.lineLimit(1)` + `.truncationMode(.tail)` เสมอ** |
| มุมชิป | 5 | เล็กกว่า `Radius.control` เพราะแถบสูงแค่ 17 |

### 3.2 หัวเดือน / ปี

- หัวเดือนใหญ่ (24pt semibold) **อัปเดตตามเดือนที่อยู่บนสุดของจอ** ขณะเลื่อน
  ใช้ `.onScrollGeometryChange` หรือ `.scrollPosition(id:)` ผูกกับ id ของ `MonthSection` — **ห้ามใช้ `GeometryReader` ต่อแถวเพื่ออ่านตำแหน่ง** จะกินแรงเครื่องทันที
- ปีอยู่ใต้ชื่อเดือน แตะแล้วเป็น `Menu` เลือกปี — **ช่วง: ปีปัจจุบัน −1 ถึง +2** (พ.ศ.)
  เปลี่ยนปีแล้ว `ScrollView` เด้งไปเดือนมกราคมของปีนั้น
- ปุ่ม **"วันนี้"** ขวาบน — เลื่อนไปเดือนปัจจุบันแล้ว select วันนี้ · ถ้าปีที่ดูอยู่ไม่ใช่ปีปัจจุบัน ให้สลับปีให้ด้วย
- แถวชื่อวัน **ปักหมุด** (`pinnedViews: [.sectionHeaders]` หรือวางนอก `ScrollView`) — ห้ามเลื่อนหายไป
- เสาร์/อาทิตย์ใช้สี `textSecondary` ที่จางกว่าวันธรรมดา (ในตารางไทยมักเน้นวันหยุด — ที่นี่ใช้ "จางลง" ไม่ใช่ "แดง" เพราะแดง = `danger` มีความหมายอื่นในระบบ)

### 3.3 ชิป 2 แบบ — ต้องแยกออกจากกันด้วยตา

| ชนิด | หน้าตา |
|---|---|
| **กิจกรรมปฏิทิน** (`CalendarEvent`) | พื้นทึบ `event.color.opacity(0.18)` · ตัวอักษรสีเข้มของ hue เดียวกัน · ไม่มีขอบ |
| **งาน / การบ้าน** (`Assignment`) | พื้น `cardBackground` · **ขอบ 1pt สีวิชา** · มีวงกลมกลวงเล็กนำหน้า |
| **งานที่เสร็จแล้ว** | เหมือนงานปกติแต่ `.opacity(0.45)` + `.strikethrough()` |

- ข้อความในชิป = **ชื่ออย่างเดียว** ไม่มีเวลา (Few เลือก) — พื้นที่ 5-6 ตัวอักษรไม่พอใส่เวลา
- ท่อนต่อจากสัปดาห์ก่อนเติมคำว่า `" (ต่อ)"` ต่อท้ายชื่อ

## 4. หัวใจของงาน — อัลกอริทึมจัดเลน

**ต้องเป็นฟังก์ชันบริสุทธิ์ ไม่ import SwiftUI** เพื่อให้เทสต์ได้โดยไม่ต้องมี `ModelContainer` — แบบเดียวกับ `GPAXCalculator` และ `RIASECScorer`

ไฟล์ใหม่: `Core/Calendar/MonthLayoutEngine.swift`

```swift
struct LaidOutBar {
    let itemID: String
    let lane: Int          // 0...3
    let startColumn: Int   // 0...6
    let columnSpan: Int    // 1...7
    let isContinuation: Bool
}

struct WeekLayout {
    let bars: [LaidOutBar]
    let overflowByColumn: [Int: Int]   // column → จำนวนที่ซ่อน
}

enum MonthLayoutEngine {
    static func layout(
        items: [CalendarItem],
        weekStart: Date,
        maxLanes: Int = 4,
        calendar: Calendar
    ) -> WeekLayout
}
```

**กฎการจัดเลน (ห้ามเปลี่ยนลำดับ):**

1. ตัดทุกรายการให้เหลือเฉพาะช่วงที่ทับกับสัปดาห์นี้ → ได้ `(startColumn, columnSpan)`
2. เรียง: **span มากก่อน** → ถ้าเท่ากันเรียงตาม `startColumn` → ถ้ายังเท่าเรียงตาม `createdAt`
   (span มากก่อน เพราะแถบยาวควรได้เลนบนสุด ไม่งั้นจะโดนแถบสั้นแทรกจนขาดวิ่น)
3. ไล่ทีละรายการ หาเลนแรก (0 ขึ้นไป) ที่ทุกคอลัมน์ใน span ยังว่าง → จอง
4. ถ้าไม่มีเลนว่างใน 0…3 → ไม่ต้องวาง แต่ `overflowByColumn[c] += 1` ให้ทุกคอลัมน์ที่รายการนั้นกิน
5. `isContinuation = true` เมื่อวันเริ่มจริงอยู่ก่อนวันแรกของสัปดาห์นี้

⚠️ **`overflowByColumn` ต้องนับต่อคอลัมน์ ไม่ใช่ต่อสัปดาห์** — ไม่งั้นวันที่ว่างจะขึ้น `+3` ทั้งที่ไม่มีอะไรซ่อนอยู่

**เทสต์ที่ต้องมี** (`StudiiOSTests` ยังเป็น template เปล่า — นี่คือโอกาสใส่ของจริง):
- อีเวนต์ 1 วันเดียว → lane 0 span 1
- อีเวนต์ 3 วันไม่ทับใคร → lane 0 span 3
- อีเวนต์ยาวข้ามสัปดาห์ → สัปดาห์ที่สองต้อง `isContinuation == true` และ `startColumn == 0`
- 6 อีเวนต์วันเดียวกัน → 4 ตัวได้เลน · `overflowByColumn[c] == 2`
- อีเวนต์ยาวล้นเลน → ทุกคอลัมน์ที่มันกินต้อง `+1` เท่ากันหมด

### 4.1 โครงการวาดหนึ่งแถวสัปดาห์

**ห้ามให้แต่ละช่องวันวาดชิปของตัวเอง** — แถบพาดข้ามช่องไม่ได้ถ้าทำแบบนั้น

```
ZStack(alignment: .topLeading) {
    HStack  ← 7 ช่องวัน: เลขวัน + พื้นหลัง + tap target (ไม่มีชิป)
    ForEach(bars) → วางด้วย .offset(x: colWidth * startColumn,
                                    y: laneTop + laneHeight * lane)
                        .frame(width: colWidth * span - gap)
}
```

`colWidth` มาจาก `GeometryReader` ระดับแถว **ครั้งเดียวต่อแถว** ไม่ใช่ต่อช่อง

## 5. ลากย้ายวัน — เขียน hit-test ใหม่

Few เลือก **เก็บฟีเจอร์นี้** และ **ลากแถบหลายวันได้ ย้ายทั้งก้อนโดยคงจำนวนวันเท่าเดิม**

### 5.1 สิ่งที่พังจากของเดิมและต้องเขียนใหม่

| ของเดิม | ปัญหา | ทางแก้ |
|---|---|---|
| `gridSize` ตัวเดียว | มีหลายเดือนแล้ว | เก็บ `[monthKey: CGRect]` ของแต่ละ `MonthSection` ผ่าน `.onGeometryChange(for: CGRect.self) { $0.frame(in: .named("calScroll")) }` — **12 รายการ ไม่ใช่ 365** |
| `cellIndex(at:)` | คิดจากตารางเดียว | หา section ที่ครอบจุดนั้นก่อน → แล้วค่อยคิด row/col ภายใน |
| `hitTestItem(at:cellIndex:)` | ชิปอยู่ในช่อง | ตอนนี้แถบมี frame ชัดเจนจาก `LaidOutBar` → hit-test ตรงกับ frame ของแถบเลย **ง่ายกว่าเดิม** |
| ปล่อยนอกจอ | — | ScrollView ต้องถูกล็อกระหว่างลาก |

### 5.2 แผน 2 เฟส — ทำเฟส 1 ให้จบก่อน

**เฟส 1 (บังคับ):**
- `.scrollDisabled(true)` ระหว่างลาก — กันนิ้วไปสู้กับการเลื่อน
- ปล่อยได้เฉพาะวันที่**มองเห็นอยู่บนจอ** ถ้าปล่อยนอกพื้นที่ → `flyBack()` เหมือนเดิม
- ย้ายไปเดือนไกลๆ ใช้วิธีเปิดฟอร์มแล้วแก้วันที่แทน

**เฟส 2 (ทำถ้าเวลาเหลือ — ตัดได้):**
- ลากค้างใกล้ขอบบน/ล่าง 60pt แล้วเลื่อนหน้าอัตโนมัติ
- ⚠️ auto-scroll ระหว่าง drag ใน SwiftUI `ScrollView` เป็นจุดที่พังง่ายที่สุด **ห้ามเริ่มเฟส 2 ก่อนเฟส 1 จะ build ผ่านและ Few กดลองแล้ว**

### 5.3 ย้ายแถบหลายวัน

```swift
let span = event.endDate.timeIntervalSince(event.startDate)
event.startDate = newStart
event.endDate   = newStart.addingTimeInterval(span)
```
- ต้องคง `isAllDay` และเวลาในวัน (ชั่วโมง/นาที) เดิมไว้
- ยิง `NotificationManager.schedule(for: event)` ใหม่เสมอ (เมธอดนี้ยกเลิกของเดิมให้เองอยู่แล้ว)
- `moveTask` ของ `Assignment` คงเดิม — งานมีวันเดียว
- **เก็บ `moveToast` + ปุ่มเลิกทำไว้ทั้งหมด** เป็นของดีที่มีอยู่แล้ว

| `LazyVStack` ทำให้ frame ของเดือนที่ยังไม่ render เป็นศูนย์ | กลาง | ระหว่างลากให้ถือว่าเดือนที่ยังไม่ render = ปล่อยไม่ได้ (flyBack) |
| เลื่อนแล้วหัวเดือนกระพริบ | กลาง | อัปเดตหัวเดือนแบบ throttle ไม่ใช่ทุกเฟรม |
| แตะชิปกับกดค้างลากชนกัน | กลาง | `.onTapGesture` + `.simultaneousGesture(LongPressGesture(0.35).sequenced(before: DragGesture()))` — เกณฑ์เดิมของ ghost ใช้ได้ ยกมา |
| แตะช่องว่างแล้วโดนชิปแทน | ต่ำ | ช่องวันอยู่ชั้นล่างของ `ZStack` แถบอยู่ชั้นบน → แตะโดนแถบก่อนอัตโนมัติ ถูกต้องแล้ว |

## 9. เกณฑ์เสร็จ

1. เปิดแท็บ/เมนูปฏิทิน → เห็นตารางเดือนใหญ่ เลื่อนขึ้นลงได้ตลอด 12 เดือนในปีนั้น
2. แถวชื่อวัน อา–ส **ไม่เลื่อนหายไป**
3. หัวเดือนเปลี่ยนตามที่เลื่อนถึง
4. แตะปี → เลือกปีอื่นได้ · กด "วันนี้" → เด้งกลับเดือนปัจจุบัน
5. **อีเวนต์ 3 วันแสดงเป็นแถบเดียวพาด 3 ช่อง** ไม่ใช่ชิป 3 ใบ
6. อีเวนต์ที่ข้ามสัปดาห์ → สัปดาห์ถัดไปขึ้นแถบต่อพร้อมคำว่า (ต่อ)
7. วันที่มีเกิน 4 รายการ → ขึ้น `+N` **เฉพาะวันนั้น** วันข้างๆ ที่ว่างต้องไม่ขึ้น
8. งานที่เสร็จแล้วยังเห็นอยู่ จางลงและมีขีดฆ่า
9. แตะชิป → เปิดฟอร์มของรายการนั้นทันที · แตะช่องว่าง → sheet รายวันเด้งครึ่งจอ
10. **กดค้างแถบ 3 วันแล้วลากไปวางวันอื่น → ย้ายทั้งก้อน ยังยาว 3 วันเท่าเดิม** และมี toast ให้เลิกทำ
11. ไม่มี FAB และไม่มีการ์ดรายการใต้ตารางแล้ว
12. สลับ dark mode → แถบทุกสียังอ่านออก
13. `MonthLayoutEngineTests` ผ่านทั้งหมด
