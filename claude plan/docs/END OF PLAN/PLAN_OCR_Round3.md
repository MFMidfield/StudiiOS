### 🔴 F1 · คาบโฮมรูมหายทั้งคอลัมน์ — ค่าคงที่ตัวเดียว

**ที่:** `TableGridBuilder.swift` L168

```swift
guard length >= 20, length <= 180 else { return nil }
```

**อาการ:** คาบโฮมรูมของโรงเรียนนี้คือ `08.15-08.30` = **15 นาที** → ถูกตัดทิ้งว่าเป็นขยะ

**ไล่หลักฐาน:**

| candidate | สมาชิก | ทำไม |
|---|---|---|
| `numericHeaderCandidate` | 7 | Vision อ่านเลข `0` `5` `6` `8` ไม่ออก (ได้แค่ #08–#14 = 1,2,3,4,7,9,10) |
| `timeCandidate` | 10 | 11 ช่วง ลบ `08.15-08.30` ที่ guard ตัด |

10 > 7 → `bestPositions` เลือกแถวเวลา → `fitAxis` ได้ `origin = 0.215` `count = 10`
โฮมรูม (x 0.145) คำนวณได้ index **−1** → `Axis.index(for:)` L72 คืน nil → ทิ้งทั้งคอลัมน์

ตรงกับ output เป๊ะ: บรรทัดแรกเป็น `จันทร์ ค0 08:30-09:20` ไม่มีโฮมรูมสักแถว

**แก้:** `length >= 20` → `length >= 10`
`00.00-00.00` ยังถูกกรองอยู่เพราะ length = 0 ✓ ไม่เสียการกันขยะ

**ราคา:** 1 บรรทัด

### 🔴 F2 · บรรทัดห้องตกไปแถวถัดไปทุกแถว — ข้อมูลผิดแบบเงียบ

**ที่:** `TableGridBuilder.swift` `contentShift` L481–494

**อันตรายที่สุดในลิสต์** เพราะข้อมูลไม่ได้หาย แต่ไปโผล่ผิดที่ **โดยไม่มีธงเตือน**

**หลักฐานจาก output:**

```
จันทร์ ค0  831102 · ครูศิริรัตน์          ← ไม่มีห้อง
อังคาร ค0  831102 · ครูศิริรัตน์ · 236    ← "236" ตัวนี้คือห้องของจันทร์ (#27)
ศุกร์ ค2   ว31282 · ครูวรัญญา · 236       ← ในกระดาษเป็น 238 (#86)
```

**กลไก:** แกนวัน pitch = 0.1312 → แถบรับ ±0.0656 แต่เนื้อหาในช่องกิน 0.072

```
รหัส   y 0.706  (= anchor "โฮมรูม")   residual   0
ครู    y 0.671                        residual  −0.035
ห้อง   y 0.634                        residual  −0.072  ← เกินครึ่ง step
```

`contentShift` L487 คำนวณ index จากแกน **ที่ยังไม่ได้ shift** (ไก่กับไข่)
→ บรรทัดห้องถูกปัดไป index+1 → residual พลิกจาก −0.072 เป็น **+0.059**
→ ไปหักล้างกับ −0.035 ของบรรทัดครู

median ของทั้งหมด (รหัส ≈ 0 · ครู ≈ −0.035 · ห้อง ≈ +0.059 จำนวนพอกัน) → **ตกที่ 0**
→ `shift = 0` → ไม่แก้อะไรเลย ค่าที่ถูกคือ **−0.036**

**แก้ที่เสนอ:** เลิกใช้ median ของ residual ที่คำนวณจากแกนตัวเอง
แทนด้วย: สำหรับ anchor แต่ละแถว เก็บ content box ที่อยู่ในระยะ ±1 step
แล้วตั้ง origin เป็น **กึ่งกลางระหว่าง min กับ max ของเนื้อหานั้น**

> ทางเลือกสำรอง: วนซ้ำ 2–3 รอบ (คำนวณ shift → ปรับแกน → คำนวณใหม่) ง่ายกว่าแต่เนียนน้อยกว่า

**ราคา:** ~30 บรรทัด

### 🟠 F3 · การโหวตถูกอดอาหาร — เหตุผลที่ "ถูกเลย" เหลือ 6 จาก 35

**ที่:** `ScheduleOCRParser.swift` L298 + L367–371


ตารางนี้มี `.alreadyValid` แค่ **6 จาก 35** → ledger แทบว่าง → โหวตช่วยอะไรไม่ได้เลย

| #87 | `230202` | ครูปิยดา | ✅ `ว30202` | ✓ |
| #38 | `030202` | ครูปิยลา | ⚠️ `ง30202` | **ว30202** |
| #60 | `030202` | ครูปิยตา | ⚠️ `ง30202` | **ว30202** |

> ⚠️ **ห้ามเปลี่ยนกฎเอกฉันท์เป็นเสียงข้างมาก** — คอมเมนต์ L139–144 อธิบายไว้แล้วว่าทำไม
> (tail `32101` ใช้ร่วม 6 วิชา เสียงข้างมากจะพังมากกว่าแก้)
>
> การขยาย ledger นี้**ไม่ชนกับกฎเอกฉันท์** เพราะเส้นทางที่แก้ #38/#60 ได้คือ **ผูกกับครู**:
