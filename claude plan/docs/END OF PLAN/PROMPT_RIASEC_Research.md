# บทบาท

คุณคือนักจิตวิทยาการแนะแนว (career counseling psychologist) ที่เชี่ยวชาญทฤษฎี Holland's RIASEC และการปรับใช้เครื่องมือวัดความสนใจข้ามวัฒนธรรม (cross-cultural adaptation of interest inventories) โดยเฉพาะกับบริบทการศึกษาไทย

# ภารกิจ

ค้นคว้าและออกแบบ **ชุดคำถามคัดกรองความสนใจอาชีพ (RIASEC screening inventory) จำนวน 18 ข้อ** สำหรับนักเรียนไทยระดับ ม.1–ม.6 เพื่อประเมิน "เบื้องต้น" ว่าผู้ตอบมีแนวโน้มไปทางมิติใดใน 6 มิติของ Holland

**ย้ำ:** นี่คือเครื่องมือ *คัดกรองเบื้องต้น* (screening) ไม่ใช่เครื่องมือวินิจฉัย (diagnostic) การออกแบบและการเขียนผลลัพธ์ต้องสะท้อนข้อจำกัดนี้อย่างซื่อสัตย์

# บริบทของผลิตภัณฑ์ (สำคัญมาก — มีผลต่อข้อจำกัดในการออกแบบ)

- แอป iOS ชื่อ Student OS สำหรับนักเรียนไทย ม.1–ม.6
- **ทำงานแบบ offline 100%** — การให้คะแนนต้องคำนวณด้วยสูตรง่ายๆ ในเครื่องได้ ห้ามพึ่ง API หรือโมเดล AI
- ผู้ใช้ตอบแบบสอบถามบนมือถือ ต้องจบภายใน **ไม่เกิน 3 นาที**
- UI ทั้งหมดเป็นภาษาไทย ผลลัพธ์จะเชื่อมต่อไปยังการเลือก **คณะ/สาขาในระบบ TCAS ของไทย**
- แสดงผลเป็น **3 อันดับพร้อมเปอร์เซ็นต์ความเข้ากัน** ไม่ใช่คำตอบเดียว

# ขั้นตอนที่ต้องทำ (ทำตามลำดับ)

## ขั้นที่ 1 — ค้นคว้าฐานทางวิชาการ

ค้นหาและอ้างอิงแหล่งข้อมูลจริง โดยให้ความสำคัญกับ:

1. **O*NET Interest Profiler (Short Form 60 ข้อ / Mini-IP 30 ข้อ)** — เผยแพร่โดย U.S. Department of Labor เป็น **public domain** ใช้เป็นฐานได้โดยไม่ติดลิขสิทธิ์ ให้ดึงโครงสร้าง item, สเกล, และวิธีให้คะแนนมาอ้างอิง
2. **IPIP RIASEC Markers (Goldberg, 1999)** — public domain อีกชุดหนึ่ง มี item pool ให้ใช้ฟรี
3. งานวิจัยที่ตรวจสอบ **ความตรงของโครงสร้าง RIASEC ในกลุ่มตัวอย่างเอเชีย/ไทย** — โดยเฉพาะประเด็นว่า circumplex structure ของ Holland fit กับวัฒนธรรมเอเชียได้ดีเพียงใด (ค้นคำว่า "RIASEC measurement invariance Asian samples", "Holland's model cross-cultural validity Thailand")
4. งานวิจัยเรื่อง **ความยาวขั้นต่ำของ interest inventory ที่ยังคง reliability ยอมรับได้** (short-form validity, Cronbach's α ต่อ scale)

**ข้อควรระวังด้านลิขสิทธิ์ — ต้องระบุในผลลัพธ์:**

- **Self-Directed Search (SDS)** ของ Holland และ **Strong Interest Inventory** เป็นเครื่องมือ **มีลิขสิทธิ์เชิงพาณิชย์** → ห้ามคัดลอก item มาใช้ อ้างอิงเชิงแนวคิดได้เท่านั้น
- ต้องระบุชัดว่า item ที่คุณเสนอแต่ละข้อ **เขียนขึ้นใหม่ (original)** หรือ **ดัดแปลงจากแหล่ง public domain ใด**

## ขั้นที่ 2 — ออกแบบชุดคำถาม 18 ข้อ

ข้อกำหนด:

- **3 ข้อต่อมิติ** (R, I, A, S, E, C × 3 = 18) เพื่อให้แต่ละมิติมีมากกว่า 1 ข้อรองรับ (single-item scale ไม่น่าเชื่อถือ)
- แต่ละข้อวัด **มิติเดียวเป็นหลัก** (คะแนนน้ำหนัก 1.0) แต่อนุญาตให้มี **cross-loading รอง** ได้ไม่เกิน 1 มิติ (น้ำหนัก 0.3–0.5) เพราะความสนใจในชีวิตจริงไม่แยกขาดจากกัน
- ภาษาต้อง **นักเรียน ม.1 อ่านเข้าใจ** — ประโยคสั้น ไม่มีศัพท์วิชาการ ไม่มีคำทับศัพท์ที่ไม่จำเป็น
- **ต้องอยู่ในบริบทไทย** — อ้างอิงกิจกรรมที่นักเรียนไทยเคยเจอจริง (ชุมนุม/ชมรม, งานกลุ่ม, กิจกรรมวันวิชาการ, การประกวด, งานจิตอาสา, ค่าย) ห้ามใช้ตัวอย่างที่มีแต่ในโรงเรียนอเมริกัน เช่น prom, homecoming, varsity team
- **ห้ามมี gender stereotype** — เลี่ยง item ที่งานวิจัยพบว่าเกิด differential item functioning ตามเพศ (เช่น "ซ่อมเครื่องยนต์" มักโหลด R สูงในผู้ชายด้วยเหตุผลทางสังคม ไม่ใช่ความสนใจจริง) ถ้าจำเป็นต้องใช้ item แนวนี้ ให้เลือกกิจกรรมที่เป็นกลางกว่า
- **ห้ามถามถึงอาชีพโดยตรง** (เช่น "อยากเป็นหมอไหม") เพราะนักเรียนตอบตามภาพจำ/ความคาดหวังของพ่อแม่ ไม่ใช่ความสนใจ → ให้ถามถึง **กิจกรรม** แทน
- **สเกล 5 ระดับ** (1 = ไม่ชอบเลย → 5 = ชอบมาก) พร้อมเสนอข้อความกำกับแต่ละระดับเป็นภาษาไทย

## ขั้นที่ 3 — ออกแบบวิธีให้คะแนน

- สูตรคำนวณคะแนนดิบต่อมิติ และวิธีแปลงเป็น **เปอร์เซ็นต์ความเข้ากัน** ที่เข้าใจง่าย (ระบุสูตรให้ชัด ต้อง implement ใน Swift ได้ในไม่กี่บรรทัด)
- วิธีจัดการปัญหาที่พบบ่อย: **response bias** (ตอบ 5 ทุกข้อ / ตอบ 3 ทุกข้อ) → เสนอวิธี normalize เช่น ipsative scoring หรือหักค่าเฉลี่ยของผู้ตอบเอง พร้อมอธิบายข้อดีข้อเสีย
- วิธีสร้าง **Holland Code 3 ตัวอักษร** (เช่น RIA) จากคะแนน และเกณฑ์ตัดสินเมื่อคะแนนใกล้เคียงกันมาก (tie-breaking)
- เกณฑ์ว่าเมื่อไรควรบอกผู้ใช้ตรงๆ ว่า **"ผลยังไม่ชัดพอ"** แทนที่จะยัดเยียดคำตอบ (เช่น เมื่อ 3 อันดับแรกต่างกันไม่เกิน X%)

## ขั้นที่ 4 — แมปสู่คณะไทย

สำหรับแต่ละมิติใน 6 มิติ ให้เสนอ **คณะ/สาขาในมหาวิทยาลัยไทย 4–6 คณะ** ที่สอดคล้อง พร้อมระบุ:

- ชื่อคณะ/สาขาตามที่ใช้จริงในระบบ TCAS
- Holland Code ที่ตรงกับคณะนั้น (2–3 ตัวอักษร)
- วิชาที่ควรเน้นในระดับมัธยม

ถ้ามีแหล่งอ้างอิงการแมป RIASEC กับสาขาวิชาไทยที่ตีพิมพ์แล้ว ให้อ้างอิง ถ้าไม่มี ให้ระบุตรงๆ ว่าเป็นการแมปโดยผู้เชี่ยวชาญ ไม่ใช่ผลวิจัยเชิงประจักษ์

# รูปแบบผลลัพธ์ที่ต้องการ

ตอบเป็น **ภาษาไทย** แบ่ง 5 ส่วนตามนี้:

### ส่วนที่ 1 — สรุปฐานทางวิชาการ (ไม่เกิน 400 คำ)

ระบุว่าใช้อะไรเป็นฐาน อ้างอิงงานวิจัยชิ้นไหน และ **ข้อจำกัดของ RIASEC ที่รู้กันในวงวิชาการ** (เช่น ทำนายความพึงพอใจในงานได้ดีกว่าทำนายความสำเร็จ, circumplex structure fit ไม่ดีนักในกลุ่มนอกอเมริกาเหนือ)

### ส่วนที่ 2 — ชุดคำถาม 18 ข้อ (เป็น JSON)

```json
[
  {
    "id": 1,
    "text": "คำถามภาษาไทย",
    "primary": "R",
    "primaryWeight": 1.0,
    "secondary": "I",
    "secondaryWeight": 0.4,
    "source": "adapted from O*NET Interest Profiler item #12 / original",
    "rationale": "เหตุผลสั้นๆ ว่าทำไม item นี้วัดมิติ R"
  }
]
```

### ส่วนที่ 3 — สูตรให้คะแนน

เขียนเป็น pseudocode ที่แปลงเป็น Swift ได้ตรงๆ พร้อมตัวอย่างการคำนวณ 1 เคส

### ส่วนที่ 4 — ตารางแมปมิติ → คณะไทย

| มิติ | ชื่อไทย | Holland Code | คณะ/สาขา | วิชาที่ควรเน้น |

### ส่วนที่ 5 — ข้อความ disclaimer ที่ควรแสดงในแอป

ร่างข้อความภาษาไทยสั้นๆ (2–3 บรรทัด) ที่บอกผู้ใช้อย่างซื่อสัตย์ว่าผลนี้เป็นเพียงจุดเริ่มต้นในการสำรวจตัวเอง ไม่ใช่คำตัดสิน และควรปรึกษาครูแนะแนวประกอบ

# สิ่งที่ห้ามทำ

- ห้ามคัดลอก item จากเครื่องมือที่มีลิขสิทธิ์ (SDS, Strong, MBTI)
- ห้ามกล่าวอ้างความแม่นยำเกินจริง — ถ้าไม่มีงานวิจัยรองรับ ให้บอกว่าไม่มี
- ห้ามอ้างอิงงานวิจัยที่คุณไม่ได้ค้นเจอจริง (ถ้าหาไม่เจอ ให้บอกว่าหาไม่เจอ)
- ห้ามเสนอคำถามเกิน 18 ข้อ
